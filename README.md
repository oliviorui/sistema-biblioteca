# sistema-biblioteca
Sistema que vai automatizar e flexibilizar o processo de registo de entrada e saída dos estudantes de uma biblioteca.
Este projeto é um MVP (Produto Mínimo Viável) que permite registrar entradas e saídas de estudantes, gerar relatórios básicos e facilitar a gestão da ocupação da biblioteca. Totalmente web, leve, e pronto para evoluir com tecnologias modernas.
